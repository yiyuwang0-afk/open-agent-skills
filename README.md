# Public Codex Skills

This repository contains sanitized Codex skills intended for public sharing.

## Skills

- `obsidian-knowledge-flow`: import external material into Obsidian, classify notes with open content topics, optionally route notes into long-term topic hubs, and receive Feishu/Lark forwarded messages.

## Privacy

Do not commit real vault paths, `.env` files, API keys, Feishu/Lark credentials, private diary content, work notes, or scraped article bodies.
